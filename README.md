# 🌍 7 Keajaiban Dunia (7 Wonders of the World)

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Vercel-black?style=for-the-badge&logo=vercel)](https://tugas-web-keajaiban-dunia.vercel.app/)

## 📖 Deskripsi Proyek
Website ini menyajikan informasi mengenai 7 Keajaiban Dunia. Proyek ini dibangun sebagai tugas sekolah sekaligus menjadi wadah untuk melatih dan mengeksplorasi *skill* desain antarmuka menggunakan CSS. 

Banyak orang terkadang lupa akan landmark bersejarah yang ada di dunia. Oleh karena itu, website ini hadir untuk mengingatkan dan mengedukasi kembali pengunjung tentang keajaiban-keajaiban luar biasa tersebut dengan cara yang simpel dan menarik.

## ✨ Fitur Utama
*   **Dark Theme UI:** Tampilan antarmuka website mengusung tema gelap (*dark mode*) yang elegan, membuat gambar dan teks lebih menonjol serta nyaman di mata.
*   **Informasi Ringkas & Informatif:** Penjelasan untuk setiap keajaiban dunia dibuat singkat, padat, dan jelas, sehingga pembaca langsung memahami esensinya tanpa harus membaca teks yang terlalu panjang.
*   **Live Deployment:** Proyek sudah di-deploy sehingga dapat diakses kapan saja dan di mana saja.

## 💻 Teknologi yang Digunakan
Proyek ini dibangun menggunakan teknologi dasar web:
*   **HTML** - Sebagai kerangka dan struktur utama halaman.
*   **CSS** - Untuk *styling*, tata letak (*layout*), dan pewarnaan tema gelap.
*   **JavaScript** - Untuk menambahkan elemen interaktivitas pada halaman web.
